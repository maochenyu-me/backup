# Teek 视觉改造修订方案

状态：待用户确认。本文修订原主题迁移设计中的外观策略；本轮仅写文档，不改页面代码，不提交或部署。

## 1. 修订原因与目标

用户反馈换主题后打开仍是原来的效果。代码检查确认：虽然入口继承 Teek，但首页仍使用原来的 Home.vue，四份旧 CSS 继续在主题之后覆盖色板、正文、表格和布局。此前验证证明了依赖接入与功能兼容，不能证明视觉目标已经实现。

本次属于既有主题迁移的架构修订：重新划分主题框架、首页和业务样式的责任。目标是让首页和文档页都有可辨认的结构变化，而不是仅增加几个圆角。保留内容与查阅效率，不改成博客。

尚未确认用户正在访问的 URL，因此不把线上页面、旧预览或缓存作为已证实原因。实施验收必须标明正在看的本地地址及页面版本。

## 2. 路线比较

| 路线 | 效果与代价 | 结论 |
| --- | --- | --- |
| A：Teek 文档框架 + 原生 Hero/任务入口 + 文档内容面 | 保留成熟主题；首页结构明显改变；只定制手册业务区域 | 推荐 |
| B：Teek 博客演示布局 | 最接近博客演示，但文章流、作者栏与换机任务不匹配 | 不采用 |
| C：继续修补旧双栏首页 | 风险低，但仍容易看起来和原来一样 | 不采用 |

不承诺只开一个 Teek 开关就能得到特殊文档外观。主题负责导航、侧栏、目录与基础交互；本站只补充明确的手册首页和内容面，不复制主题内部布局。

## 3. 预期可见变化

### 首页

- 移除原来的“左导语 + 右窄清单”masthead 主体布局，不再原样挂载旧 Home.vue。
- 使用 VitePress 原生 Hero（由 Teek 文档框架承载）：站名、定位文案和三个现有任务操作。无壁纸、无渐变。
- Hero 下方显示八步任务区域：桌面四列两行、中屏两列、手机单列。每个步骤显示现有序号、名称和入口，不编造完成状态。
- 版本速查表独立为有标题的内容面，保留现有八行事实；安全提醒单独显示在其下方。
- 首页仍是执行入口，不加入文章列表、作者头像或博客归档。

### 文档页

- 冷灰页面底色与白色正文内容面形成层次；深色对应深灰底和略亮内容面，不让正文继续与整页背景混成一片。
- 桌面侧栏与正文有明确间距，当前侧栏条目清楚高亮；右侧目录保持轻量。
- 正文内容面圆角约12px、细边框、无重阴影；手机取消多余外框和大内边距，优先阅读空间。
- 保留原生代码组、复制按钮、提示块和标题基础样式，撤掉旧 CSS 对这些元素的全面压平覆盖。
- 保留软件胶片头、版本徽标、配置定义列表和时间线的语义；重画外观，使它们与新内容面一致，而不是旧终端交接单样式原封不动叠上来。

### 颜色与交互

保留青色品牌与系统字体；允许布局和内容面变化，不仅改强调色。明暗切换、搜索、移动导航沿用现有机制；不启用主题偏好控制面板、评论、统计、外部字体和非必要动画。

## 4. 文件与责任边界

- `docs/index.md`：声明 Hero 文案和三个入口；链接沿用已测试的 base/cleanUrls 策略，准确接入方式在实施计划核实。
- `Layout.vue`：只使用公开插槽组织首页任务区，保留单一主题布局及单页脚。
- 首页展示组件：步骤、版本表、安全提示按职责组织；不引入新的状态管理或额外内容源。
- `tokens.css`：只保留品牌、字体、必要明暗变量，不全面重设主题排版。
- `components.css`：只保留胶片头、徽标、定义列表、时间线等业务样式；删除全局表格、提示块、标题压平规则。
- 首页 CSS：用新的首页组件作用域替代旧 masthead 与补丁，避免新旧样式同时生效。
- 独立文档框架样式：有限地控制正文内容面、侧栏间距与窄屏行为，不修改主题源文件，不依赖构建哈希。

原有 DSH / DSH-TUI 安装正文、URL、人工导航、版本信息和核对日期不变。依赖版本保持 Teek1.6.2 / VitePress1.6.4；继续保留内部文档双重排除与部署回归检查。

## 5. 验收标准

1. 首页结构不再是旧 masthead 双栏；桌面八步为四列两行，390px为单列，三个主入口和八步链接全部可用。
2. 文档桌面清楚呈现页面底/侧栏/正文内容面层次；手机正文不因内容面而挤窄、代码和表格只在自身滚动。
3. 首页、Node.js、DSH、DSH-TUI、换机顺序、备份清单保持单 H1，明暗模式均无页面级横向溢出。
4. 根路径、嵌套base、cleanUrls=false的构建、链接和主题产物检查通过，安装正文与核对日期不被改写。
5. 浏览器实测搜索、侧栏、目录、代码组、复制、明暗切换和移动菜单。复制必须获得焦点后核对完整命令；权限受阻如实标记未完成。
6. 在同一明确本地地址展示改造后的首页和文档页，请用户直接核对外观。截图/DOM几何测量不能替代视觉验收；当前读图通道若仍被能力声明拦截，必须请用户查看，不宣称视觉验收通过。
7. 无新外部字体、统计、评论请求；不部署、不推送、不自动提交。
